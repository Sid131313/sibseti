# Тарифы: установка и обслуживание

Публичная страница запрашивает только свой файл `/data/tariffs/{город}.json`. Внешний сайт нужен исключительно скрипту обновления.

## Первичная настройка

1. Загрузите проект на Beget целиком.
2. Админка по умолчанию закрыта (`admin/tariffs/.htaccess`). Укажите настоящий абсолютный путь к файлу паролей в `admin/tariffs/.htaccess.example`, затем замените этим файлом `admin/tariffs/.htaccess` и создайте файл паролей командой `htpasswd` вне `public_html`.
3. Проверьте наличие расширений PHP `curl`, `dom` и `mbstring`.
4. Запустите импорт вручную: `php parser/update-tariffs.php`.

Для Cron в Beget используйте (подставьте настоящий путь аккаунта):

```text
/usr/bin/php /home/ACCOUNT/public_html/parser/update-tariffs.php >/dev/null 2>&1
```

Запуск — раз в сутки, например в 03:00. Скрипт защищён от параллельного запуска через `flock`.

## Ручное изменение

Откройте `/admin/tariffs/?city=novosibirsk` после защиты Basic Auth. Изменение поля создаёт override в `data/overrides/{город}.json`; это значение имеет приоритет над импортом. Кнопка «Вернуть авто: поле» удаляет override у конкретного поля. Снятие флажка «Показывать» скрывает тариф и не будет отменено обновлением.

Чтобы добавить собственный тариф без админки, создайте/дополните `data/manual/{город}.json` массивом объектов. Пример:

```json
[{"id":"manual-nsk-special","source":"manual","city":"novosibirsk","category":"internet","name":"Специальный тариф","speed":500,"price":900,"active":true,"sort":5}]
```

Чтобы полностью закрепить импортированный тариф, добавьте в его override `"manual_lock": true` (это служебное поле доступно при редактировании JSON). Удалённый с источника тариф остаётся только при наличии override или `manual_lock`; иначе скрывается при очередном корректном импорте.

## Данные и диагностика

- Автоматический snapshot: `data/source/{город}.json`.
- Итог для сайта: `data/tariffs/{город}.json`.
- Ручные корректировки: `data/overrides/{город}.json`.
- Ручные тарифы: `data/manual/{город}.json`.
- До 10 резервных копий: `data/backups/tariffs/`.
- Статус каждого запуска: `data/status/{город}.json`.
- Лог: `logs/tariffs-parser.log`.

Если источник вернёт ошибку, пустую страницу или ноль тарифов, предыдущий публичный JSON остаётся без изменений. Сильное уменьшение числа тарифов и трёхкратный скачок цены фиксируются в логе как предупреждения. Пороги находятся в `parser/config.php`.

Все перечисленные города из сайта добавлены в `parser/config.php`; у Новосибирска источник — корень `https://sibsetipro.ru/`, у остальных — `https://sibsetipro.ru/{slug}/`. Если источник переименует URL города, измените только его `source` в конфиге.
